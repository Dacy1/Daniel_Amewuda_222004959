## Project Overview

A personal portfolio website with a PHP-based admin panel for content management. The project includes a public portfolio showcasing professional experience and projects, plus a complete admin system for managing all content.

## Features Implemented

### 1. Admin Portal System
- Super Admin with login access
- Admin creation and management
- Role-based access control

### 2. Admin Authentication
- Secure login with username and password
- Password encryption using PHP hashing
- Session management

### 3. Admin Dashboard
- Dashboard with statistics overview
- Navigation to all admin functions

### 4. Project Management
- Add, edit, delete portfolio projects
- Image upload for projects
- Technology tags and project links

### 5. About Section Management
- Edit personal information and contact details
- Social media links management

### 6. Contact Message Management
- View submitted contact messages
- Mark messages as read/unread
- Delete messages

### 7. Blog Posts Management
- Add, edit, delete blog articles
- Draft/Published status management

### 8. Skills Management
- Add, edit, delete skills
- Categorize skills by type

### 9. Experience & Education
- Work experience management
- Education records management

### 10. Secure Logout
- Proper session handling and logout

---

## Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP, MySQL
- **Security:** Password hashing, SQL injection protection

## Installation

1. Clone the repository
2. Create MySQL database: `portfolio_db`
3. Import the database.sql file
4. Update database credentials in config.php
5. Access portfolio at `/index.php`
6. Admin panel at `/admin/login.php`
